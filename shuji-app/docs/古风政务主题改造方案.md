# 枢机前端 — 古风政务主题改造方案

> **版本**：v1.0  
> **日期**：2026-05-31  
> **目标读者**：Coding Agent / 前端开发者  
> **范围**：`shuji-app/src/` 前端 UI，不含 Rust 后端  
> **原则**：阅读舒适优先；古风体现在字体、色、间距、结构；装饰从简（Restrained）

---

## 0. 已确认的产品决策

| 决策项 | 选定方案 |
|--------|----------|
| 发送按钮文案 | **呈奏**（全 app 统一，不再使用「发送」） |
| 正文字号 | **16px**（`1rem`），行高 **1.75**；UI 控件最小 **14px** |
| 装饰强度 | **Restrained（克制版）**：版式 + 色 + 字体 + 少量线条；**不做**全屏纹理、水印、大面积花纹 |
| 标题字体 | Display / h1–h3 用 **Noto Serif SC**；长文正文用 **Noto Sans SC** |
| 代码修改 | 按本文档分 Phase 实施；每 Phase 结束跑 `npm run build` 确保无 TS 错误 |

## 1. 问题诊断（现状）

当前阅读不舒适的主要原因：

1. 大量 `text-[9px]` / `text-[10px]` / `text-[11px]`（侧栏、状态栏、Chat tab、DocTree）
2. `globals.css` 声明了 `Noto Serif SC`、`Inter`，但 `index.html` **未加载字体**
3. 辅助文字多用 `ink-400`/`ink-500`，对比度偏低
4. Markdown / 聊天在宽屏下**行宽不受控**
5. 底部 `DeptStatusBar` + `LogBar` 双栏常驻，信息过密
6. Emoji 作图标（ActivityBar、顶栏），风格不统一
7. 部分组件仍用 `gray-*`、`red-600` 等，未走 `ink/vermillion/gold/jade` token
8. `WorkflowTimeline.tsx` 使用旧 gray 色板，与主界面脱节（需接入或删除）

## 2. 设计 Token（写入 `src/styles/globals.css`）

在现有 `@theme` 块中**扩展**以下内容，并新增 `@layer utilities` 工具类。

### 2.1 字号与行高

```css
/* ── Typography scale ── */
--text-display: 1.875rem;   /* 30px — 页面大标题「枢机」 */
--text-title:   1.25rem;    /* 20px — 区块标题、文档 h2 */
--text-subtitle: 1.125rem;  /* 18px — 卡片标题 */
--text-body:    1rem;        /* 16px — 正文（聊天、Markdown、表单输入）★ */
--text-ui:      0.875rem;    /* 14px — 按钮、侧栏、标签、Tab ★ 最小 UI 字号 */
--text-caption: 0.8125rem;   /* 13px — 时间戳、路径、统计（全 app 最小字号） */

--leading-body: 1.75;
--leading-ui:   1.5;
--leading-tight: 1.35;

--measure-prose: 42rem;   /* ~672px — 文档正文最大宽度 */
--measure-chat:  38rem;   /* 聊天气泡区参考宽度 */
```

**硬性规则（Coding Agent 必须遵守）：**

- 任何**可读段落**（聊天 content、Markdown body、帮助文案、表单 label 下方说明）≥ **16px**
- UI 控件（按钮、树节点、Tab、Badge）≥ **14px**
- 全项目**禁止** `text-[9px]`、`text-[10px]`、`text-[11px]`
- 辅助信息最低 **13px**，颜色用 `text-ink-600` 或更深，**禁止**大面积 `ink-400` 作正文辅助

### 2.2 面色与边框

```css
/* ── Surfaces ── */
--color-surface-paper:    #FDFBF7;   /* 奏纸 — 主阅读区、聊天区背景 */
--color-surface-parchment: #F5F0E8;  /* 侧栏、卡片、输入框浅底 */
--color-surface-elevated: #FFFFFF;   /* 气泡、弹层 */

/* ── Borders ── */
--color-border-subtle:  #E8E0D4;
--color-border-fold:    #D9D0C1;     /* 折线、卡片描边 */
--color-border-accent:  #C4B8A2;

/* ── Text ── */
--color-text-primary:   #2C2416;     /* = ink-900 */
```

### 2.6 Prose 统一样式 `.prose-shuji`

## 3. 基础组件库（新建 `src/components/ui/`）

抽组件以减少内联重复，**全项目强制复用**。

### 3.1 `Button.tsx`

```tsx
type Variant = "primary" | "secondary" | "ghost" | "danger" | "seal";

// primary: bg-ink-900 text-ink-50 hover:bg-ink-800
// secondary: border border-fold bg-surface-elevated text-ink-800 hover:bg-ink-100
// ghost: text-ink-600 hover:bg-ink-100
// danger: bg-vermillion text-white hover:bg-vermillion-dark
// seal: border-2 border-vermillion text-vermillion hover:bg-vermillion-light（御批/outline CTA）

// 统一: text-sm (14px), px-4 py-2, rounded-lg, font-medium, transition-colors
// disabled: opacity-40 cursor-not-allowed
```

### 3.2 `Badge.tsx`

部门标签、文档 type_label、状态（in_review / approved）。

### 3.3 `Card.tsx`

```tsx
type Variant = "paper" | "parchment" | "ink";

// paper: bg-surface-elevated border border-fold rounded-xl shadow-sm
```

## 6. Restrained 装饰规范（推荐版细则）

### 6.1 印章 Logo（唯一图形装饰）

新建 `SealLogo.tsx`：

- 32×32 或 40×40 SVG
- 方形圆角边框 `stroke: vermillion`，内为 serif「枢」或「枢机」一字
- 用于：`WorkspaceSelect` 卡片顶部、`ProjectDashboard` 顶栏项目名左侧（16×16 小版）

**禁止**：全屏 watermark、纸纹 background-image、动画祥云。

### 6.2 线条装饰（可用）

| 位置 | 做法 |
|------|------|
| 顶栏底 | `border-b border-gold/30` |
| 区块标题 | `.title-rule-gold` |
| 卡片 | `border border-fold`，`rounded-xl`，`shadow-sm` |
| 分隔「或」 | 双线 + 居中文字（WorkspaceSelect 已有，保留） |

### 6.3 动效（克制）

- 部门活跃：`animate-pulse` 仅用于圆点，不用整行闪
- 尊重 `prefers-reduced-motion: reduce` → 关闭 pulse
- 过渡：`transition-colors duration-150` 即可，不做 elaborate 动画

### 6.4 不做清单

- ❌ 全屏水墨 / 宣纸 texture
- ❌ 正文使用 serif
- ❌ Emoji 图标
- ❌ 9–11px 字号
- ❌ 高饱和大面积红/金背景
