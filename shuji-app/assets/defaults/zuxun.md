# 祖训 — 项目规范

适用于所有项目的通用开发公约。

## 一、完备性
- 必须有清晰的目标和范围定义
- 必须明确技术选型及其理由
- 必须提供整体架构描述

## 二、可行性
- 技术方案应有先例或参考依据——不得捏造未经检验的方法
- 工期估算必须包含缓冲余量
- 资源需求必须如实列明

## 三、安全
- 用户数据必须在存储和传输中加密
- 特权操作必须有不可绕过的校验机制
- 外部接口必须有输入验证和错误处理

## 四、结构
- 模块边界必须明确，职责清晰
- 模块间依赖必须显式声明，不得存在循环引用
- 数据流和状态变更必须可追溯

## 五、惯例
- 前端不得直连数据库，始终通过后端 API
- 密钥、令牌等敏感信息不得硬编码
- 数据库必须有索引和迁移策略
- 日志必须记录关键操作——既不缺失也不泛滥
