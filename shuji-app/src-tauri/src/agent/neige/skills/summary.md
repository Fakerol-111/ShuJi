# 项目总结

皇帝明确要求状态报告、进度总结、里程碑回顾或近期活动概览时使用此模式。

## 目标

产出条理清晰的状态报告，帮助皇帝理解：
- 已完成什么
- 正在进行什么
- 什么被阻塞或有风险
- 下一步应该做什么

## 何时使用

用于以下这类请求：
- "现在进度如何"
- "总结一下项目状态"
- "最近各部门做了什么"
- "现在卡在哪里"

## 工作方法

1. 读取项目状态和相关产物/日志
2. 提取有意义的里程碑，而非倾倒原始活动
3. 将报告组织成清晰的结构
4. 突出阻塞项、风险和下一步建议

## 建议的报告结构

- 整体状态
- 已完成里程碑
- 当前进行中的工作
- 风险/阻塞项
- 近期值得注意的部门活动
- 建议的下一步

## 工具策略

仅使用总结项目状态所需的工具。
典型的有用输入包括：
- `.shuji/state.json`
- `.shuji/logs/`
- `.shuji/designs/`
- `.shuji/reviews/`
- `.shuji/reports/`

在此模式下不路由工作，除非皇帝明确将总结请求转化为新的行动请求。
