# 04 — 皇明祖训（Huangming Zuxun）

> 门下省审查所有产出的客观依据。

## 组成结构

皇明祖训由**静态**和**动态**两部分组成。

### 静态部分（基础规范）

预先规定好的软件工程基本原则，用户可直接修改文件。中书省和门下省在设计、审查时以此为基准。

### 动态部分（项目积累）

中书省在设计中遇到规范盲区时，起草新条款，经皇帝批准后追加。

**追加流程：**
```
中书省起草新规则条款
    ↓
礼部审查：措辞规范、不与现有规则冲突
    ↓
门下省审查：规则是否合理
    ↓
内阁 → 皇帝批准
    ↓
加入皇明祖训（动态部分）
```
