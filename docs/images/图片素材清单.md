## 图2: 文档驱动 vs 对话驱动对比图

**文件名**: `doc-vs-chat.mmd`
**用途**: 放在第三节第2点（文档即项目记忆），直观展示两种通信模式的差异
**建议尺寸**: 宽 1200px

```mermaid
graph LR
    subgraph chat[" ❌ 对话驱动：上下文漂移"]
        direction LR
        A1["Agent A<br/>设计方案"]:::chatNode
        C1["对话<br/>上下文"]:::chatCtx
        A2["Agent B<br/>编码实现"]:::chatNode
        C2["对话<br/>上下文"]:::chatCtx
        A3["Agent C<br/>测试验证"]:::chatNode

        A1 -->|"口头交代"| C1
        C1 -->|"靠记忆理解"| A2
        A2 -->|"口头交代"| C2
        C2 -->|"靠记忆理解"| A3

        D1["❌ 长上下文信息丢失"]:::problem
        D2["❌ Agent 切换后前文不可靠"]:::problem
        D3["❌ 项目历史无法沉淀"]:::problem
    end

    subgraph doc[" ✅ 文档驱动：文档即契约"]
        direction LR
        B1["Agent A<br/>产出设计文档"]:::docNode
        DOC1[("📄<br/>dsgn_3.md<br/>YAML frontmatter<br/>refs: [1,2]")]:::docStore
        B2["Agent B<br/>read_document<br/>获取完整信息"]:::docNode
        DOC2[("📄<br/>plan_5.md<br/>YAML frontmatter<br/>status: in_review")]:::docStore
        B3["Agent C<br/>read_document<br/>获取完整信息"]:::docNode

        B1 -->|"create_document"| DOC1
        DOC1 -->|"read_document(id=dsgn_3)"| B2
        B2 -->|"create_document"| DOC2
        DOC2 -->|"read_document(id=plan_5)"| B3

        E1["✅ 信息永不衰减"]:::benefit
        E2["✅ RefIndex 双向引用索引"]:::benefit
        E3["✅ 项目结束 = 完整文档链"]:::benefit
    end

    classDef chatNode fill:#fee2e2,stroke:#dc2626,color:#7f1d1d
    classDef chatCtx fill:#fef2f2,stroke:#f87171,color:#991b1b,stroke-dasharray: 3 3
    classDef docNode fill:#dcfce7,stroke:#16a34a,color:#14532d
```

## 图3: Pipeline 引擎执行流程（建议补充）

**文件名**: `pipeline.mmd`
**用途**: 放在第三节第1点，展示内阁定计划 → 引擎执行的完整链路
**建议尺寸**: 宽 1200px

```mermaid
graph TB
    Neige["🏛 内阁<br/>分析任务 → 输出 PipelinePlan JSON"]:::neige

    subgraph engine["Pipeline 引擎（确定性执行）"]
        direction TB
        Parse["解析 DAG 依赖"]:::engine
        Find["find_executable_step()"]:::engine
        Exec["执行步骤"]:::engine
        Check{"结果?"}:::engine
        Done["标记 Done"]:::engine
        Deadlock{"死锁检测<br/>find_executable_step() = None"}:::engine
    end

    subgraph actions["5 种步骤动作"]
        AskUser["ask_user<br/>询问用户"]:::action
        RouteTo["route_to<br/>路由到部门"]:::action
        Parallel["parallel<br/>并行执行"]:::action
        Gate["approval_gate<br/>朱批审批"]:::action
        SelfExec["self_execute<br/>内阁自执行"]:::action
    end

    subgraph failure["失败处理"]
        Playbook["📋 Playbook<br/>test-red<br/>contract-mismatch<br/>lint-fail<br/>pipeline-deadlock"]:::playbook
        Retry{"retry < 上限?"}:::engine
        WakeNeige["失败 → wake_cabinet<br/>内阁重新规划"]:::fail
        Skip["跳过继续"]:::fail
        Abort["终止流水线"]:::fail
    end

    Neige -->|"submit_pipeline_plan"| engine
    Parse --> Find
    Find --> Exec
    Exec --> actions
    Exec --> Check
    Check -->|"成功"| Done
    Done --> Find
    Check -->|"失败"| failure
    failure --> Playbook
    Playbook --> Retry
    Retry -->|"是"| Exec
    Retry -->|"否"| WakeNeige
    WakeNeige --> Neige

    Find -->|"无步骤可执行"| Deadlock
    Deadlock -->|"死锁"| WakeNeige

    classDef neige fill:#dbeafe,stroke:#2563eb,color:#1e3a5f
    classDef engine fill:#f3f4f6,stroke:#6b7280,color:#1f2937
    classDef action fill:#ede9fe,stroke:#7c3aed,color:#4c1d95
    classDef playbook fill:#fef9c3,stroke:#ca8a04,color:#713f12
    classDef fail fill:#fee2e2,stroke:#dc2626,color:#7f1d1d
```
